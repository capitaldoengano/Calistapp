# Calistenia 90 v3
Programa completo de 12 semanas / 36 sessões (A, B e C), com progressão específica por semana.

Inclui:
- 36 sessões planejadas
- 12 fases semanais
- progressões e regressões
- timer de descanso
- registro de sessão
- sequência por datas
- medidas e teste
- PWA + funcionamento offline após primeiro carregamento

Abra `index.html` ou publique a pasta em HTTPS para instalar no celular.
